`mint guard` ships 32 listed rules: 29 pattern rules and 3 environment checks. A Shannon-entropy detector runs on top of them.

```bash
mint guard rules
mint guard rules --format json
```

The replacement command is a starting point, not the rotation itself. Rotate at the provider first.

## Environment rules

These are used by `mint guard env` and are included in `mint guard rules`.

| Rule id | Severity | Detects | Replacement command |
| --- | --- | --- | --- |
| `env-file-tracked` | critical | `.env` file tracked by git | `mint token --bytes 32` |
| `env-file-not-ignored` | high | `.env` file not ignored | `mint token --bytes 32` |
| `env-no-example` | low | No `.env.example` while env files exist | `mint password --length 32 --no-ambiguous` |

## Entropy detection

The entropy detector catches secrets with no known format. It looks at quoted strings and assignment values, then applies these rules:

- Length from 20 to 200 characters.
- Shannon entropy of at least 4.5 bits per character by default.
- Reject UUIDs, known digests, git hashes, URLs, file paths, source snippets, images, alphabets, prose and placeholders.
- Reject values already matched by a pattern rule on the same span.

```bash
mint guard scan --entropy-threshold 5
mint guard scan --entropy-threshold 4
```

Higher is stricter. Tune it only after looking at the findings. The synthetic rule id is `entropy-string`; it can be disabled in config:

```json
{
  "disabledRules": ["entropy-string"],
  "entropySeverity": "high",
  "entropyThreshold": 4.5
}
```

It can also be selected with `--rules entropy-string`, even though it is not printed as a row in the 32-rule list.

## Filtering

```bash
mint guard scan --rules github-token,entropy-string
```

`--rules` accepts a comma-separated list. Unknown ids are an error. `--fail-on` controls the gate, not which rules run.

## Reading the JSON rule list

```bash
mint guard rules --format json
```

Each entry contains the id, name, severity, keywords, why text, replacement command, rotation key and a `builtIn` flag. Custom rules from `.mintguard.json` appear here too.
